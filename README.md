# PHẦN MỀM TRẮC NGHIỆM TIẾNG ANH: PRONOUNS AND REFERENCING (20 CÂU HỎI)
### TRƯỜNG CAO ĐẲNG CÔNG NGHỆ THỦ ĐỨC (TDC)

Ứng dụng web trắc nghiệm trực quan, hiện đại gồm 20 câu hỏi trọng tâm chuyên đề **Pronouns and Referencing** (Đại từ phản thân, tính từ sở hữu, đại từ sở hữu, đại từ thay thế one/ones, another/the other/others, đại từ tương hỗ each other...).

---

## 🌟 ĐẶC ĐIỂM NỔI BẬT

1. **Chuẩn 100% 20 câu hỏi theo đề bài yêu cầu**:
   - Bộ 20 câu hỏi ngữ pháp chuẩn quốc tế, kiểm tra toàn diện các kiến thức về đại từ và phép quy chiếu.
   - Đáp án chuẩn xác, kiểm duyệt nghiêm ngặt.

2. **Logo TDC ở góc trên cùng bên trái**:
   - Logo chính thức của Trường Cao đẳng Công nghệ Thủ Đức được đặt trang trọng ở góc trên bên trái thanh điều hướng.

3. **Bố cục tối ưu đặc biệt cho Điện thoại & iPad**:
   - **Khung câu hỏi đặt ở bên dưới cùng** khi hiển thị trên điện thoại hoặc iPad (dạng bottom-docked card), giúp người học dùng ngón tay cái thao tác bấm chọn cực kỳ thuận tiện và tự nhiên.
   - **Câu hỏi và 4 lựa chọn (A, B, C, D) cùng nằm gọn trong 1 khung duy nhất**, đảm bảo không bị tách rời hay trôi layout trên mọi kích thước màn hình.

4. **Bảo mật khi làm bài & Giải thích chi tiết sau khi nộp**:
   - **Lúc làm bài**: Tuyệt đối **không** hiển thị bất kỳ gợi ý, cờ đúng/sai hay đáp án nào bên cạnh câu hỏi.
   - **Sau khi nộp bài**: Kích hoạt chế độ Xem lại (Review Mode):
     * Làm nổi bật đáp án đúng (màu xanh lá kèm huy hiệu `✓ Đáp án đúng`).
     * Hiển thị lựa chọn của sinh viên nếu chọn sai (màu đỏ kèm huy hiệu `✗ Lựa chọn của bạn`).
     * Khung **Giải thích chi tiết & Dịch nghĩa** hiển thị ngay trong khung câu hỏi:
       - 🇻🇳 **Dịch nghĩa**: Dịch nghĩa trọn vẹn ngữ cảnh câu hỏi sang tiếng Việt trong sáng, dễ hiểu.
       - 📚 **Giải thích ngữ pháp**: Phân tích cặn kẽ tại sao lại dùng đáp án đó, quy tắc ngữ pháp tương ứng và vì sao các phương án khác chưa chính xác.
     * Hỗ trợ nút **"Xem trọn bộ 20 câu"** để sinh viên có thể lướt đọc lại toàn bộ bài thi và giải thích một cách nhanh chóng.

5. **Theo dõi số lượng người đăng nhập / truy cập khi đưa lên GitHub**:
   - **Bộ đếm trực tiếp (Live Visitor Counter)**: Hiển thị ngay trên thanh điều hướng số lượt người truy cập vào hệ thống.
   - **Hệ thống đăng nhập thông tin sinh viên**: Sinh viên có thể nhập Họ tên, Mã số sinh viên (MSSV) và Lớp học phần trước khi làm bài.
   - **Bảng Thống kê & Quản trị dành cho Giảng viên (Admin Dashboard)**:
     * Nhấp vào nút `📊 Thống kê` trên góc phải.
     * Thống kê tổng số lượt truy cập link, số lượt đã nộp bài, điểm trung bình của cả lớp.
     * Bảng danh sách chi tiết từng sinh viên: Họ tên, MSSV, Lớp, Điểm số (trên 20), Thời gian làm bài, Ngày giờ nộp bài.
     * **Nút xuất Excel (`📥 Tải về file Excel (CSV)`)**: Giảng viên có thể tải về file bảng điểm lớp đầy đủ chỉ với 1 cú click!
   - **Theo dõi qua GitHub Insights**: Hướng dẫn chi tiết cách xem biểu đồ người dùng thực tế trên GitHub Traffic.

6. **Các tiện ích khác**:
   - Bộ chuyển đổi nhanh chế độ xem **PC / iPad / Mobile** ngay trên màn hình để kiểm tra giao diện.
   - Đồng hồ đếm thời gian làm bài.
   - Chế độ Sáng / Tối (Light Mode / Dark Mode).
   - Hỗ trợ phím tắt bàn phím trên máy tính (`←` / `→` để chuyển câu; `1, 2, 3, 4` hoặc `A, B, C, D` để chọn đáp án).

## 🚀 HƯỚNG DẪN CHẠY TRÊN MÁY LOCAL (MÁY TÍNH CÁ NHÂN)

### Cách 1: Chạy bằng file Batch (Khuyên dùng - 1 Click)
1. Mở thư mục `d:\websiteabc\PRONOUNS AND REFERENCING`
2. Nhấp đúp chuột vào file **`run_local.bat`**
3. Trình duyệt mặc định sẽ tự động mở trang web tại địa chỉ: `http://localhost:8080` (hoặc `8081`).

### Cách 2: Mở trực tiếp file HTML
1. Nhấp đúp chuột trực tiếp vào file **`index.html`**.
2. Ứng dụng sẽ chạy ngay lập tức trên trình duyệt mà không cần cài đặt thêm bất kỳ phần mềm nào.

### Cách 3: Chạy bằng PowerShell
```powershell
cd "d:\websiteabc\PRONOUNS AND REFERENCING"
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

## 🌐 HƯỚNG DẪN ĐƯA LÊN GITHUB PAGES & THEO DÕI NGƯỜI ĐĂNG NHẬP

### Bước 1: Tạo Repository trên GitHub
1. Đăng nhập vào [GitHub](https://github.com/) của bạn.
2. Bấm nút **New Repository** (Tạo repo mới).
3. Đặt tên, ví dụ: `tdc-pronouns-referencing`. Chọn chế độ **Public** và bấm **Create repository**.

### Bước 2: Tải code lên GitHub
Mở PowerShell tại thư mục này và chạy các lệnh:
```powershell
cd "d:\websiteabc\PRONOUNS AND REFERENCING"
git init
git add .
git commit -m "Initial release of TDC Pronouns and Referencing Quiz"
git branch -M main
git remote add origin https://github.com/<tai-khoan-cua-ban>/tdc-pronouns-referencing.git
git push -u origin main
```

### Bước 3: Kích hoạt GitHub Pages (Miễn phí 100%)
1. Vào repository trên GitHub > bấm tab **Settings** (Cài đặt).
2. Ở menu bên trái, chọn mục **Pages**.
3. Tại phần **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)`, sau đó bấm **Save**.
4. Sau khoảng 1-2 phút, GitHub sẽ cung cấp link trang web công khai có dạng:
   `https://<tai-khoan-cua-ban>.github.io/tdc-pronouns-referencing/`
5. Gửi đường link này cho sinh viên làm bài thi trên điện thoại, iPad hoặc máy tính!

### Bước 4: Cách Giảng viên theo dõi số lượng người đăng nhập và truy cập link
1. **Xem trực tiếp trên trang web**:
   - Góc trên bên phải thanh điều hướng có huy hiệu `Truy cập: X lượt`.
   - Giảng viên bấm nút **`📊 Thống kê`** để xem tổng số lượt truy cập, danh sách sinh viên đã nộp bài và tải file Excel (CSV).
2. **Xem qua GitHub Traffic Insights (Thống kê chuyên sâu từ máy chủ GitHub)**:
   - Vào Repository trên GitHub > Bấm vào tab **Insights** (ở thanh menu trên cùng của repository).
   - Chọn mục **Traffic** ở cột menu bên trái.
   - Tại đây GitHub cung cấp biểu đồ:
     * **Visitors**: Số người dùng duy nhất đã truy cập vào link theo từng ngày.
     * **Views**: Tổng số lượt xem/truy cập trang web.
     * **Referring sites**: Các nguồn giới thiệu dẫn sinh viên đến link bài thi.
